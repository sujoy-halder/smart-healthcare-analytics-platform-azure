# Informatica Integration Scope

This folder contains import-ready mapping specifications for Informatica Cloud or
PowerCenter implementation teams. It separates MDM, clinical terminology mapping,
and payer-feed normalization from the Azure-native runtime.

Real deployment requires the customer Informatica org, secure agents, source
connectors, source credentials, and private network connectivity to Epic, Cerner,
SQL Server, Oracle, SFTP, and payer systems.
